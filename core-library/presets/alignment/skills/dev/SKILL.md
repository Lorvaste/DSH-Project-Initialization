## 调度规则

- 触发：技术选型/论证请求、重复性/合规检查 → 调度对应子 skill（检查类 + verify 调度）
- 子 skill 单职责、可单独调用；跨类调用须经主 skill 或用户指令

## 本类规则

- 论证/评审立场声明：推导假设先声明；评审严厉程度与检验维度（可行性/必要性/重复性）先声明（RD-1）
- 开发前情境假设先核对：需求已打包？定档依据齐全？（RD-2）
- 检验结论三态：评审/检验结论 = 扮演假设级，未经用户确认不生效（RD-3）
- 最优解基于真实数据模拟推导，禁止假设性结论
- 开发类仅提供模板（tech-selection 等），不预设开发流程
- AI 不实际参与调研：检索只提供资料与缺口标注，判断由用户决定
