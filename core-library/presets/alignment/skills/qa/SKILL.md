# qa（统合问答系统）

- 模式：入口先确认
- 模式一：需求收集与设计（req，完善补充想法）
- 模式二：技术选型与技术设计（dev-pre，基于需求定档论证）

## 问答行为

- 一次几问：用户决定
- 带选项 / 示例
- 中途可切换
- 不诱导
- 不评判
- 隐式假设：逼出（追问"正常/按惯例"等模糊词）
- 矛盾检测：请用户裁决
- 完成标准：用户确定，不设上限
- 细则补充四方式：推导自动 / 问答逐个 / 问答批量 / 范围推导确认
- 问答模板：易/难决策两类，按需不强制

## 记录

- 决策表：ID / 决定 / 依据 / 状态 / 来源
- 理解强度：分级
- 未定义项：盘点

## 输入

- 初稿文件 → 通读 → 复述 → 确认

## 输出

- qa-record.md（内部，Other/requirements/）
