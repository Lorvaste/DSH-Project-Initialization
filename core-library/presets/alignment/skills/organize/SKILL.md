# organize（规格化整理 + 文档再编排）

## 规格化模式（req）

- 问答成果 → F/D/R/I + MOD 归属
- 输出：requirements-list.md + requirements-structure.md（根目录）

## 全量再编排模式（mnt，先行）

- 扫描 → 统一化 → 归类 → 检查 → 报告 + structure.md
- 统一化：英文命名 / 结构 / 术语
- 归类：公开 / 内部
- 检查：空白 / 冲突 / 重复 + 占位符

## 刚性

- 文档名只用英文
- 每项改动可追溯：原路径 → 新路径 → 理由
- 移动执行：用户逐项确认后
