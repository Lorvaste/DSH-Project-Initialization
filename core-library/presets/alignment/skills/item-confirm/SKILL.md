# item-confirm（F12）

- 点名确认：列出待确认项（编号）明确请求
- 确认绑定：确认 = 用户对当前点名编号项的明确回应；上下文回复/沉默/陈述句/扮演假设均不算确认
- **授权范围核对**：确认前核对该项操作是否在本轮用户授权范围内；授权外操作单独请示（与操作分级 PG-4 联动）
- 逐条确认：已确认 / 待定 / 驳回
- 未确认项不进下一阶段；驳回项重新澄清再确认
- 确认后立即写入决策表（ID/决定/依据/状态/来源=用户确认）
- 返回 ≠ 确认：AI 的"已理解/好的"不是确认
- **误认回退**：发现误把上下文当确认执行 → 复述实际执行内容 → 用户确认 → 修正记录
