# verify（遍历性检查）

## 检查执行

- 三层遍历：目标 / 域 / 条目
- 七维度 + 领域模板
- 三查：空白 / 冲突 / 重复

## 报告（按证据机制）

- 结论附证据来源
- 明确"什么不算证据"
- 反证据对照
- 红旗词（应该/大概/看起来/就这一次/部分检查够了）→ 触发显式确认
- 按维度展示检查过程与结果

## 生效

- 结果经用户确认后生效
- 影响面复验
- 与 organize 检查不统合

## 输出

- 验证报告 → 维护场景 audit/；其他阶段 Other/
